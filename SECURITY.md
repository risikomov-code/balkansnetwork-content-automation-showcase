# Public Showcase / Security Boundary

This repository is intentionally **not** a deployable copy of the BalkansNetwork production editorial system.

## Public

- project purpose
- high-level content workflow
- design principles
- technology and capability areas
- non-sensitive case-study narrative

## Private

- credentials and tokens
- production URLs and infrastructure details
- WordPress plugin source code
- workflow exports and node logic
- prompts and system instructions
- internal editorial rules and scoring logic
- full taxonomies and state schemas
- source databases
- media/provider identifiers
- retry, fallback and cost-control logic
- production logs and analytics
- contributor, client or business-confidential information

No secret, private dataset, production export or deployable implementation should ever be committed to this repository.
